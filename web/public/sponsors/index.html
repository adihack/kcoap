Sponsoring kcoap

kcoap has no sponsors yet, and there is no way to sponsor it yet. Sponsorship will go through GitHub Sponsors or Open Collective; this page will link the account once one exists.

Why

Why sponsorship matters here

kcoap is security code that people should read before they trust it, maintained by one person.

Its claims rest on things that cost money to keep running: interop against independent implementations on every pull request, CI on Linux and macOS, real devices to test on, and a review of the cryptographic code by someone other than its author.

Sponsors buy no influence

Sponsorship gives no say over technical decisions, the roadmap, reviews or disclosure, and no early access to vulnerability information. Sponsors may say that they sponsor kcoap; calling themselves an official partner, or using the logo, needs written permission.

Sponsors will be listed in SPONSORS.md, in the README and on this page; details such as logos come with the accounts.

Today

How to help now

Money is one way to help. These help as much, and work today.

Report interop results

Ran kcoap against a device, a gateway or another CoAP, OSCORE or EDHOC implementation? Open an issue with what you ran, what you saw, and a capture if you have one. Results from real devices are what the project lacks most.

Report bugs and RFC gaps

A behaviour that differs from an RFC is a bug. Cite the section, and say what kcoap did. SUPPORT.md says where each kind of report goes.

Contribute code and tests

Open an issue before a large change. Tests come first, RFC vectors where they exist; every commit carries a DCO sign-off, and there is no CLA.

Read and improve the docs

A guide that confused you is worth an issue or a pull request. The docs hub lists every page.

Sponsoring before an account exists

There is no official sponsorship, support, training or certification program yet; such programs exist only when this site lists them. If your organization wants to sponsor kcoap now, write to adrian.soltys@seelso.net.

Found a vulnerability? Do not open an issue: SECURITY.md says how to report it privately.
