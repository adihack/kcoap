# kcoap-cose

COSE pieces used by OSCORE and EDHOC: COSE_Encrypt0 and the Enc_structure (OSCORE AAD, EDHOC
ciphertexts), COSE_Sign1 and Sig_structure (EDHOC signature methods), COSE_Key, CWT Claims Sets
(RFC 8392), and the x5chain / x5t header parameters (RFC 9360).

Vectors: RFC 8613 Appendix C, RFC 9529.
