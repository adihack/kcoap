# Getting help

## Read the documentation first

| Where | What it covers |
|---|---|
| [README](README.md) | what kcoap is, quick start, modules, platforms |
| [Documentation hub](docs/README.md) | every guide and reference, in one place |
| [Client and server guide](docs/guide-client-server.md) | how to write a CoAP client and server with kcoap, with security |
| Module READMEs, such as [kcoap-oscore](kcoap-oscore/README.md) | each module's purpose, API and verification |
| [RFC compliance](docs/rfc-compliance.md) | what is implemented, section by section, and what is not yet |
| [API reference](https://adihack.github.io/kcoap/) | the KDoc of every public declaration; published by each release |

## Ask in an issue

| You have | Use |
|---|---|
| a question about using kcoap | the [question form](https://github.com/adihack/kcoap/issues/new?template=question.yml) |
| a bug | the [bug report form](https://github.com/adihack/kcoap/issues/new?template=bug_report.yml) |
| a problem with another CoAP, OSCORE or EDHOC implementation | the [interop report form](https://github.com/adihack/kcoap/issues/new?template=interop_report.yml) |
| a deviation from an RFC | the [RFC compliance form](https://github.com/adihack/kcoap/issues/new?template=rfc_compliance.yml) |
| an idea for a feature | the [feature request form](https://github.com/adihack/kcoap/issues/new?template=feature_request.yml) |
| a vulnerability | **not an issue**: follow [SECURITY.md](SECURITY.md) |

Search the [existing issues](https://github.com/adihack/kcoap/issues?q=is%3Aissue) first; your
question may have an answer already. kcoap has one maintainer, who answers as time allows, usually
within a few days.

## Sponsorship and support programs

kcoap offers no paid support today. Sponsorship, and support programs if they come, will be described
at https://kcoap.dev/sponsors; [SPONSORS.md](SPONSORS.md) explains what funding pays for.
